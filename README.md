College Event Portal:

A modern and responsive College Event Portal built using HTML, CSS, and JavaScript. The website allows students to discover upcoming college events, search and filter events by category, and register for events through an interactive interface.

Project Overview:

The College Event Portal provides students with a centralized platform to discover and explore college events in one place.

The portal displays different types of events such as technical events, cultural programs, sports activities, and workshops. It provides an attractive user interface along with search, filtering, and registration functionality.

Objectives:

1. To create a centralized platform for displaying college events.

2. To allow students to easily search for events.

3.To filter events based on categories.

4.To display important event details such as date and venue.

5.To provide a simple event registration interaction.

6. To create a responsive website for different screen sizes.

7. To practice frontend development using HTML, CSS, and JavaScript.

8. To implement dynamic content using JavaScript.

Features:

1.Home Section

- Attractive hero section.

- Introduction to the college event portal.

- Quick navigation to upcoming events.

2.Event Search

Users can search for events using keywords such as:

- AI

- Hackathon

- Music

- Robotics

3.Category Filter

Events can be filtered by:

- Technical

- Cultural

- Sports

- Workshop

4.Event Details

Each event card displays:

- Event name

- Category

- Date

- Venue

- Event image

- Registration button

5. Event Registration

Users can click the Register button to register for an event. A confirmation message is displayed after registration.
 
6.Responsive Design

The website is designed to work across:

- Desktop

- Laptop

- Tablet

- Mobile devices

7.Mobile Navigation

A hamburger menu is provided for easy navigation on smaller screens.

8.Modern User Interface

The website includes:

- Dark theme

- Blue, cyan and violet gradients

- Hover effects

- Smooth animations

- Responsive event cards

- Custom scrollbar

- Poppins font
